# Lab 05 — Potato Islands

Web export of the Godot 4.7 3D platformer assignment.

- Move: W A S D
- Jump: Space
- Camera: Mouse
- Release cursor: Esc

Collect all 5 coins before reaching the goal flag in each of the two levels.

The player visual was rebuilt from the supplied Potato GLB into separate animated body, arm, and leg meshes because the source model contains no rig or animations. Each level has five measured platform gaps: walking alone cannot cross them, while the starter controller's original single jump can.
